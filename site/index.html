Built around three ideas

A Git client should get out of the way, tell you the truth, and never lock you in.

⚡

Fast, on purpose

Every Git call runs off the interface thread. Only the tab you're looking at is refreshed, by watching its files, so local changes show up with no spinning. The server is checked quietly in the background (every 2 minutes by default; pick 15 seconds to 30 minutes, or off, in Settings), so merges done on GitHub or GitLab appear by themselves. A small dot on the Settings button tells you when a new version of Treeline is ready.

🔌

Any Git provider

It drives the git you already have installed, so any remote works. No accounts, no sign-in screens, no integrations to configure.

💬

Errors that help

When something fails you get a plain explanation, numbered fixes and one-click actions — with risky options clearly marked and always confirmed.

What it does

The everyday workflow and the hard days, both covered.

Stage exactly what you mean to

Split one messy edit into clean commits. Stage a whole file, a single hunk, or just the lines you tick.

  • Stage, unstage and discard per file, hunk or line
  • Commit, amend, or commit and push in one go
  • Renames and untracked files handled correctly

Resolve conflicts without fear

Conflicts pause the operation, they never lose work. Pick ours, theirs or both for each conflict and watch the result update.

  • Side-by-side ours / theirs with an editable result
  • Hover hints that name the real branches and say what is discarded
  • Merge one fix into several release branches, with the conflicts shown first
  • Continue, skip or abort from a banner
  • Refuses to mangle files that aren't valid UTF-8

Tidy history with interactive rebase

Reorder, reword, squash, fixup, edit or drop recent commits from a simple list — no text editor, no todo files.

  • Uncommitted changes are stashed and restored for you
  • Reword keeps the full message, not just the subject
  • Pause, fix, continue — all from the app

Submodules that just work

See their state at a glance, open one with a double-click — it appears in a tab right beside its parent — and update them all in one step.

  • Initialised on demand when you open them
  • Switch every submodule to the same branch in one click, or sync, commit the new pointers and push in one dialog
  • Right-click a tab to open all its submodules at once
  • Clone with submodules; a failing submodule only warns
  • Status from a single fast query, not a slow per-module scan

One dialog to bump submodule pointers

Pick a branch and Treeline checks out the parent on it, switches every submodule to the same branch, commits the new submodule commits with your message, and can push the result.

  • Only the submodule pointers are committed, never other staged changes
  • Optionally pulls each submodule first, fast-forward only
  • Also in the right-click menu of every tab

Right-click a tab, get its actions

Fetch, pull, push, open the submodules or sync them without switching tabs first. Submodule tabs sit next to their parent in a shared colour, and closing a tab takes you back to the one you came from.

Reuse a commit message in one click

A history icon in the message box lists the latest commits of the repository and your most used messages. Click one and it is in the box.

See a file as it was

Open the history of a file, pick a commit, and read the whole file as it was at that commit or just before it, renames included.

A push that says what it will do

The Push dialog tells you how many commits go where, or that you have to pull first, and lets you choose the branch from a list.

When it fails, it explains

A rejected push isn't a wall of text. You get what happened, why, and what to do — and force options are offered last, with the consequences spelled out first.

  • About twenty common errors recognised, with fixes
  • One-click: Pull, Pull (rebase), Stash, Remove lock file
  • Force push uses force-with-lease and asks you to confirm

Looks right in the light, too

Dark and light themes, resizable panes and sidebar, a built-in terminal you can divide and dock at the bottom or the right (closing one ends its shell and everything it started), a command palette for everything (Ctrl+K), and keyboard shortcuts for the rest.

Fast where it counts

Measured on large production repositories (8,000–10,000 commits, thousands of branches, with submodules).

60–420 msworking-tree status
~210 msfirst 400 commits of history
2–3×faster submodule listing than git submodule status
0accounts to create or integrations to configure

Numbers are from our own machines and repositories; yours will vary with disk speed and repository size. Keeping repositories out of OneDrive and similar sync folders helps a lot.

Install Treeline

Download the installer for your system from the latest release. Treeline needs Git 2.30 or newer on your PATH.

🪟

Windows 10 / 11

Download the -setup.exe (or .msi) and run it. Unsigned for now: if SmartScreen warns, choose More info → Run anyway.

🍎

macOS 12+

Download the .dmg (aarch64 for Apple Silicon, x64 for Intel) and drag Treeline to Applications. Right-click → Open the first time. Tested on Apple Silicon; Intel untested.

🐧

Linux

Use the .AppImage (chmod +x, then run), the .deb (sudo apt install ./file.deb) or the .rpm. Untested.
