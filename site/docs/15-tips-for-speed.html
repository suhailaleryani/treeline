15. Tips for speed

  • Keep repositories out of OneDrive / Dropbox / network drives. Sync tools lock and rescan thousands of small files inside .git and node_modules, which makes every Git tool slow. A plain folder such as C:\dev is much faster.
  • The app refreshes by watching the files of the active tab — you don't need to press Refresh after editing in your editor.
  • Very large histories load 400 commits at a time; keep scrolling to load more.
  • Add node_modules, dist and build output to .gitignore so Git doesn't scan them.
  • Fix once, release everywhere. Put the fix on one branch, then use Merge into several branches (in More) to bring it to every release branch in one go, with the conflicts listed before anything changes.
