1. Before you start

Installing Treeline

Download the installer for your system from the latest release (open Assets at the bottom of the page), then follow the steps for your system. Install Git first if you do not have it.

Windows 10 or 11

  1. Download the …-setup.exe file (or the .msi if your organisation prefers MSI packages).
  2. Run it and follow the prompts. Treeline appears in the Start menu.
  3. The installers are not code-signed yet, so Windows SmartScreen may say Unknown publisher. Choose More info → Run anyway.

macOS 12 or newer

  1. Download the .dmg for your Mac: aarch64 for Apple Silicon (M1 and later), x64 for Intel.
  2. Open it and drag Treeline into Applications.
  3. The app is not notarised yet, so macOS may refuse to open it. Right-click the app, choose Open, then Open again. If it says the app is damaged, run xattr -dr com.apple.quarantine /Applications/Treeline.app in Terminal.

Linux

  • AppImage (any distribution): download the .AppImage, then chmod +x Treeline*.AppImage and run it.
  • Debian, Ubuntu: sudo apt install ./treeline_*.deb
  • Fedora, openSUSE: sudo dnf install ./treeline-*.rpm
  • You need WebKitGTK 4.1 (libwebkit2gtk-4.1-0), which the .deb and .rpm pull in automatically.

Linux and Intel Macs are not tested yet. Windows 10 and Apple Silicon Macs are the verified platforms. If something does not work on your system, please tell us (see Help us test in the project's README).

Once installed, the app updates itself: it tells you when a new version is out (see Version and updates below). If you would rather build it yourself, see the README's Build installers section.

Git requirement

  • Git must be installed (version 2.30 or newer) and available on your PATH. Check by running git --version in a terminal. Windows: download from https://git-scm.com. macOS: run xcode-select --install in Terminal, or brew install git. Linux: sudo apt install git (or your distribution's equivalent). The app also looks in Git's usual install folders on Windows. If it still cannot find Git, it says so and offers Locate Git…: choose the Git program (git.exe, normally in C:\Program Files\Git\cmd) and the app remembers it. You can change this later in Settings (the gear icon in the top bar, or the command palette).
  • Version and updates. The version number is at the bottom right of the window and in Settings. The app checks for a newer version a few seconds after it starts, and again every few hours. When one is out, a small blue dot appears on the Settings (gear) button in the top bar; hover it to see the version number. Open Settings to read what is new and press Install and restart. You can also check by hand with Settings → Check for updates. Nothing is downloaded or installed until you press Install and restart, and if you are offline the check just does nothing.
  • Keep Git up to date. Treeline runs your Git, so it is only as safe as that Git. If yours is older than the July 2025 security fixes for cloning and submodules, a notice appears once at start-up. Update Git (see above) before cloning or updating submodules of a repository you do not fully trust.
  • Tell Git who you are once per computer, otherwise commits are refused:
    git config --global user.name  "Your Name"
git config --global user.email "you@example.com"

Signing in

The app uses whatever Git is already set up with:

  • HTTPS remotes – the first time Git needs a password or token, your operating system's credential manager (Git Credential Manager on Windows/macOS) opens a sign-in window and remembers the result.
  • SSH remotes – your SSH key must be loaded (ssh-add -l lists loaded keys) and its public half added to your account on the server.

If a fetch/push fails with an authentication error, the app explains it and shows these steps (see section 13).
