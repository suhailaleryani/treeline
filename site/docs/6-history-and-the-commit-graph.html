6. History and the commit graph

Open History (sidebar).

  • Drag the left edge of the Author, Date or Commit column header to resize it (double-click to reset).

  • Choose how dates look. Right-click the Date column header: Elapsed time (2 h ago, then the day and month; the default), Date only (11 Jan 2026), Date and time (11 Jan 2026, 09:30) or Time and date (09:30, 11 Jan 2026). The choice applies to every repository and is remembered. Hover a date for the full date and time in any case.

  • Each row is a commit: graph lines on the left, then message, author, date, short ID. Coloured tags are branches (green), remote branches (purple), tags (amber) and where you are (blue = current branch).

  • The top row Uncommitted changes appears when you have local changes; click it to see the staged and unstaged changes in the panel below (read-only; use the Files view to stage and commit).

  • Click a commit to see its details in the panel below the list: the full message, author, date and parents, the Changed files, and the diff of the selected file. The panel always keeps room, so a tall list can never push it off the screen, even in a small window. Drag the divider between the list and the panel to resize it.

  • Drag the thin bar between the message box and Changed files to make the message taller; double-click it to go back to automatic height. Both boxes scroll on their own when their content does not fit.

  • Filters above the list: Commit (text in the message, or the start of a commit ID), Author (name or e-mail; it suggests the authors in the loaded history) and date. The date offers quick choices counted back from now (last hour, 24 hours, 7 days, 30 days) or Custom range… with a from and a to, each with a date and a time. Text is matched as plain text in any letter case, and the filters combine (all must match). Commits that do not match are dimmed; the graph itself never changes. The summary shows how many commits match, with ▲ ▼ to jump between them (it loads more history when needed). Every filter has its own ✕; the ✕ at the end of the summary clears them all. Untick All branches to show only the current branch's history.

  • Double-click a commit to check it out: its branch when it has one (a short list if several), the local copy of a remote branch when only that exists, otherwise the commit itself as a detached HEAD, after a confirmation. Uncommitted changes that would be overwritten stop the checkout with the usual explanation; nothing is discarded.

  • Highlight a branch: click a branch, remote branch or tag in the sidebar — the graph scrolls to its tip, selects its latest commit (its details open on the right) and highlights every commit reachable from it; everything else is dimmed. Click the ✕ on the “Highlighting …” chip to clear it.

  • Right-click a commit for: copy ID, check out, new branch/tag here, cherry-pick, revert, merge into current, reset the current branch to here (soft / mixed / hard), and interactive rebase from here.

  • Long histories load in pages as you scroll.

  • Compare two commits: click one commit, then hold Ctrl (Cmd on a Mac) and click a second one. The panel shows what changed between them (older → newer), file by file. Ctrl+click the second commit again, or press Clear, to go back to a single commit.

  • History of one file: right-click a file (in File status, or in a commit's list of changed files) and choose File history…. You see every commit that changed that file, even before it was renamed, and the change each one made.

  • Open the file at a commit: in the file history, pick a commit and use File at this commit to see the whole file as it was right after that commit, or File before it for the version just before it (under its old name if it was renamed). Changes goes back to the diff. Binary files cannot be shown as text, and a file over 1 MB is cut off.

  • Who changed each line (Blame): right-click a file and choose Blame…, or switch to the Blame tab in the file history window. Each line shows who last changed it, when, and in which commit; click that name to jump to the commit in the file's history. From a commit's file list, Blame at this commit… shows the file as it was then.
